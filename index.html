playable-check

一个开源的试玩广告（playable ads）合规检查工具：一次检查、多渠道规格、直接跑在本地和 CI 里。MIT 协议。

  • 静态检查：包体 ≤5MB、命名规范、零外部请求、CTA 与容器 API 调用序列
  • IAB MRAID 3.0 最佳实践检查
  • 动态检查：无头浏览器自动打通关，断言 gameReady / gameStart / gameEnd 调用
  • 性能评分：FPS 采样与内存占用（告警项）
